# Corner-Grocer-Project

1. What did you do particularly well?

I did particularly well in organizing the program using object-oriented programming principles. Creating a separate GroceryTracker class helped keep the code organized and made it easier to manage the different functions required for reading data, counting item frequencies, and displaying results. I also successfully implemented file input and output operations to store and retrieve grocery item data.

2. Where could you enhance your code? How would these improvements make your code more efficient, secure, and so on?

One area for improvement would be adding more robust error handling for file operations and user input. For example, the program could provide additional validation to prevent invalid menu selections or missing input files from causing issues. These enhancements would improve reliability, make the program more user-friendly, and reduce the likelihood of unexpected errors.

3. Which pieces of the code did you find most challenging to write, and how did you overcome this? What tools or resources are you adding to your support network?

The most challenging part was implementing the frequency tracking logic and ensuring the data was correctly read from the input file and stored for later use. I overcame this by breaking the problem into smaller tasks and testing each function individually. Resources that helped included course materials, Visual Studio debugging tools, zyBooks examples, and C++ documentation. Moving forward, I will continue using online programming references and debugging tools to strengthen my development skills.

4. What skills from this project will be particularly transferable to other projects or course work?

Several skills from this project will be valuable in future coursework and software development projects, including object-oriented programming, file handling, data management, debugging, and problem-solving. These skills can be applied to many different programming languages and software applications.

5. How did you make this program maintainable, readable, and adaptable?

I made the program maintainable and readable by separating functionality into different files and using a dedicated class to manage grocery tracking operations. Meaningful function names, consistent formatting, and organized program structure make the code easier to understand and modify. This design also makes the program adaptable because new features can be added with minimal changes to the existing code.
